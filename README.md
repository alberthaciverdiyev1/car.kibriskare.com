# car.kibriskare.com - Kuzey Kıbrıs Avtomobil Elan Portalı

Kuzey Kıbrıs Türk Cümhuriyyəti (KKTC) və beynəlxalq bazar üçün hazırlanmış müasir, çoxvalyutalı (GBP, TRY, EUR, USD) və yüksək performanslı avtomobil elan platforması.

---

## 🚀 Texnoloji Struktur

- **Framework:** Laravel 11/12 (PHP 8.2+)
- **Verilənlər Bazası:** PostgreSQL
- **Admin İdarəetmə Paneli:** Filament PHP v3 (`/admin`)
- **Ön Hissə (Frontend):** Laravel Blade + Tailwind CSS v4 + Alpine.js / ESBuild
- **Çoxdillilik:** Türkçe, Azərbaycanca, İngiliscə, Rusca

---

## 🔑 Əsas Xüsusiyyətlər

1. **Avtomobil Kataloqu & İdarəetmə (`/admin`):**
   - Markalar (`CarBrand`) və Dinamik Modellər (`CarModel`)
   - Ban növləri (`CarBodyType`) və Təchizatlar (`CarFeature`)
   - Avtosalonlar və Rəsmi Dilerlər (`Autosalon`)
   - Avtomobil elanları moderasiyası (`CarResource`)

2. **Ziyarətçi Saytı & Axtarış:**
   - Populyar Markalar şəbəkəsi
   - Marka ➔ Model dinamik asılılıq filtri
   - İl, Yürüş, Ban, Yanacaq, Sürətlər qutusu, Sükan istiqaməti (🇬🇧 Sağ / Sol sükan) filtrləri
   - Çoxvalyutalı qiymət göstəricisi (GBP £, TRY ₺, EUR €, USD $)
   - Avto-Kredit və Lizinq kalkulyatoru
   - Detallı şəkil qalereyası və texniki göstəricilər cədvəli
   - İstifadəçilər üçün addım-addım avtomobil elanı yerləşdirmə formu
